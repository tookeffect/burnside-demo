# Security Boundary

This repository is intentionally safe for public review.

It must not contain:

- TookEffect production source code;
- private Core implementation details;
- API tokens, OAuth secrets, private keys, signing material, or provider credentials;
- production target identifiers tied to customer infrastructure;
- internal verification heuristics or provider-specific private logic;
- private logs, repository contents, or customer data.

All identifiers, SHAs, digests, signatures, and external-context values in `examples/` are synthetic placeholders.

The purpose of this repository is to document the **integration contract and observable evidence boundary**, not TookEffect internals.

Security contact / product: https://tookeffect.com/
